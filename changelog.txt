v0.1.6 | 2026-10-31
* Added a COI Hub changelog covering all mod versions.
* Included changelog.txt in release ZIPs; builds now check that its latest entry matches the mod version.
* No gameplay changes. Requires Captain of Industry 0.8.8.

v0.1.5 | 2026-10-31
* Updated the mod for Captain of Industry 0.8.8 (Update 4.3).
* Migrated F8 to the new native shortcut system and registered it during game initialization.
* Preserved mixed-cargo composition when pooling connected station buffers, with separate pools for shielded and unshielded modules.
* Preserved native coasting toward lower speed limits when scaling acceleration.
* Explained the Harmony, runtime code generation and reflection notices in the mod description and linked the source code.

v0.1.4 | 2026-10-25
* Stretched settings sliders across the available window width.
* Shared cargo supply and free space between compatible connected station modules so wagon parts are served evenly.
* Preserved disabled-module, balancing, product, loading-mode and station-side boundaries, along with normal supply, power and worker restrictions.

v0.1.3 | 2026-10-25
* Applied the acceleration multiplier to braking force and refreshed native stopping-distance estimates.
* Added native sliders with 0.1 steps, value displays, minus/plus buttons and arrow-key control.

v0.1.2 | 2026-10-25
* Applied acceleration scaling to the actual native movement result.
* Scaled complete loading and unloading cycles, including connection, transfer, disconnection and animations, while preserving cargo batch quantities.

v0.1.1 | 2026-10-25
* Fixed loading older saves by delaying runtime property access until the game's post-load repair had completed.
* Preserved initialization errors and removed hooks after failed initialization.

v0.1.0 | 2026-10-25
* Added six live train settings: curve slowdown, acceleration, wagon capacity, top speed, loading speed and unloading speed.
* Added the F8 settings window and pause-menu entry, with settings stored in the save.
